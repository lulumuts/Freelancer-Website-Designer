# Freelancer Website Designer Portfolio

Portfolio website for Lulu Mutuli - Web Design Freelancer

## Features

- Responsive design with mobile menu
- Animated gradient background
- Scroll animations
- Interactive carousel showcasing featured work
- Services section
- Process workflow
- Investment packages

## GitHub Pages

This site is configured for GitHub Pages. To enable:

1. Go to your repository settings on GitHub
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Choose "main" branch and "/ (root)" folder
5. Click "Save"

Your site will be live at: `https://lulumuts.github.io/Freelancer-Website-Designer/`

## Local Development

Simply open `index.html` in a web browser to view the site locally.
